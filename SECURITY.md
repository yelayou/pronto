# Security Policy

## Supported Versions

The following versions of **pronto** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| latest (main) | :white_check_mark: |

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities via public GitHub Issues.**

If you discover a security vulnerability in this project, please report it responsibly using one of the following methods:

### Option 1: GitHub Private Vulnerability Reporting (Preferred)
Use GitHub's built-in [private vulnerability reporting](https://github.com/yelayou/pronto/security/advisories/new) to report the issue confidentially.

### Option 2: Email
Send details to the repository maintainer privately. Please include:
- A description of the vulnerability
- - Steps to reproduce the issue
  - - Potential impact
    - - Any suggested fix (optional)
     
      - ## What to Expect
     
      - - **Acknowledgement**: You will receive an acknowledgement within **48 hours**
        - - **Status updates**: We will provide updates every **7 days** while we investigate
          - - **Resolution**: We aim to resolve critical vulnerabilities within **14 days**
            - - **Credit**: Contributors who responsibly disclose vulnerabilities will be credited in the fix release notes
             
              - ## Scope
             
              - The following are **in scope** for security reports:
              - - Authentication and authorization issues
                - - Data exposure or injection vulnerabilities
                  - - Cross-site scripting (XSS) or CSRF
                    - - Security misconfigurations
                     
                      - The following are **out of scope**:
                      - - Issues in dependencies (please report to the respective maintainers)
                        - - Social engineering attacks
                          - - Denial of service attacks
                           
                            - Thank you for helping keep **pronto** secure!
